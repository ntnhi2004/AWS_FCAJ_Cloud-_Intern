### Week 5 Goals

- Gain practical knowledge of deploying Containers on AWS using ECS, EKS, and ECR.
- Understand and build Serverless applications using Lambda, API Gateway, and related AWS services.
- Gain an understanding of AWS Database solutions, including Relational, NoSQL, Analytics, and Caching.

**Time Period:** 20/07/2026 - 24/07/2026

### Week 5 Achievements

- Deploy **Containers** using ECS Fargate and EKS, and manage Images with ECR.
- Build **Serverless** applications using Lambda, API Gateway, DynamoDB, S3, and Step Functions.
- Work with **Database** services, including RDS, Aurora, DynamoDB, Redshift, and ElastiCache.
- Integrate **Containers, Serverless, and Databases** following a DevOps mindset.
