**Week 1 (22/06 - 26/06):** [Introduction to AWS and Core Services](1.1-week1/)

- Familiarize myself with the working environment, corporate culture, and regulations at Amazon Web Services Vietnam Co., Ltd.
- Gain an understanding of the key service categories, including Compute, Storage, Networking, and Database.
- Set up and verify the required accounts, tools, and working environment according to the provided guidelines.
- Develop fundamental knowledge and hands-on skills in working with Amazon EC2.

**Week 2 (29/06 - 03/07):** [AWS IAM, EC2 Deployment, VPC Networking Basics](1.2-week2/)

- Gain a solid understanding of the fundamentals of **AWS IAM, EC2, and VPC**.
- Successfully deploy, connect to, and manage **EC2 Instance**, while understanding the basic components of VPC networking.
- Understand the connection mechanism of **AWS Site-to-Site VPNC** between on-premises networks and VPCs.
- Strengthen **Python** programming skills and hands-on experience with AWS services.

**Week 3 (06/07 - 10/07):** [High Availability, Scalability, RDS, Aurora, ElastiCache, Route 53](1.3-week3/)

- Understand **High Availability** and **Scalability** concepts on AWS.
- Learn about **RDS, Aurora, and ElastiCache**.
- Practice configuring **Route 53** for DNS and traffic routing.
- Study and practice designing **AWS Architecture Patterns**.

**Week 4 (13/07 - 17/07):** [Amazon S3 Storage, CloudFront, and Integration Services](1.4-week4/)

- Learn about and optimize storage on **Amazon S3**.
- Enhance skills in managing, securing, and optimizing S3 performance.
- Learn about **CloudFront**, **Global Accelerator**, and methods for reducing content delivery latency.
- Research **FSx**, **Storage Gateway**, and system integration via **SQS**, **SNS**, and **Step Functions**.

**Week 5 (20/07 - 24/07):** [AWS Containers, Serverless Architecture, and Databases](1.5-week5/)

- Gain practical knowledge of deploying Containers on AWS using ECS, EKS, and ECR.
- Understand and build Serverless applications using Lambda, API Gateway, and related AWS services.
- Gain an understanding of AWS Database solutions, including Relational, NoSQL, Analytics, and Caching.

**Week 6 (27/07 - 31/07):** [Data & Analytics, Machine Learning, and Monitoring](1.6-week6/)

- Enhance knowledge of AWS Identity and Access Management, particularly IAM Roles.
- Understand and practice advanced access management mechanisms on AWS.
- Consolidate knowledge and prepare content for the AWS Cloud Journey report.

**Week 7 (03/08 - 07/08):** [AWS Security, VPC, and Disaster Recovery for Expense Management Application](1.7-week7/)

- Analyze and identify the functional requirements of the CloudMenu system.
- Design the ordering and order management workflows for different user groups.
- Understand the Serverless Architecture and data flow between system components.
- Explore the roles of AWS services used in the CloudMenu system.

**Week 8 (10/08 - 14/08):** [Advanced System Architecture and AWS Optimization for Expense Management Application](1.8-week8/)

- Enhance **AWS Solutions Architecture** skills with a focus on production-ready systems.
- Learn how to integrate AWS services to build flexible and automated **Serverless** systems.
- Apply the **AWS Well-Architected Framework** to evaluate and optimize the CloudMenu architecture.
- Prepare for the next stages of **IaC, DevOps, and CI/CD**.
