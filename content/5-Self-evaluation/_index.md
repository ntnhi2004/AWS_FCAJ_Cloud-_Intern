During my internship at AMAZON WEB SERVICES VIETNAM COMPANY LIMITED from June 22, 2026 to Aug 15, 2026, I had the opportunity to study and apply cloud computing knowledge through the research, design, and implementation of CloudMenu — a QR-based digital ordering system designed to be deployed on the AWS platform.

Throughout the internship, I gradually applied the knowledge gained from university, particularly in software engineering, databases, computer networking, and cloud computing, to analyze requirements and design the architecture of CloudMenu.

My main responsibilities and contributions included:

- Analyzing requirements and designing the overall architecture of CloudMenu, including the Customer, Kitchen, and management Dashboard interfaces.
- Researching and selecting AWS services suitable for a managed services and serverless architecture, including Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon DynamoDB, AWS IAM, and Amazon CloudWatch.
- Designing the main request flows between users, frontend, API, and database based on the CloudFront → S3 and API Gateway → Lambda → DynamoDB architectures.
- Studying VPC, subnets, Internet Gateway, NAT Gateway, VPC Endpoints, and Security Groups to gain a better understanding of AWS network architecture and resource protection.
- Practicing infrastructure deployment and management using Terraform, with infrastructure organized into modules to improve maintainability and scalability.
- Studying AWS security mechanisms such as IAM Policies, IAM Roles, Least Privilege, S3 Block Public Access, and HTTPS/TLS.
- Analyzing CloudMenu deployment costs, particularly for serverless, storage, and CDN services, and studying how to leverage the AWS Free Tier during the testing phase.
- Researching potential system extensions such as Amazon Cognito, AWS WAF, VPC Endpoints, CI/CD, and monitoring/alerting mechanisms.
- Preparing technical documentation, architecture diagrams, and descriptions of AWS infrastructure components to support system deployment and operation.

Through this internship, I not only strengthened my AWS knowledge but also improved my ability to independently study technical documentation, analyze problems, design architectures, troubleshoot issues, and present technical solutions. In addition to technical skills, I also gained a better understanding of the importance of discipline, time management, communication, and collaboration in a professional working environment.

### Needs Improvement

Although I achieved several positive results during the internship, I recognize that there are still areas that need further improvement:

- Improve discipline and time management, particularly in planning tasks, documenting the implementation process, and maintaining progress updates.
- Improve debugging and troubleshooting skills in distributed cloud systems, especially when working with Lambda, API Gateway, IAM, and networking-related issues.
- Strengthen AWS Security knowledge, particularly advanced IAM, network security, encryption, secret management, and production security best practices.
- Improve Terraform skills, with a focus on developing reusable infrastructure modules, managing Terraform state, and efficiently supporting multiple environments.
- Strengthen technical communication and presentation skills, especially when explaining architecture, technology choices, and design decisions.
- Continue studying production-ready architectures, including CI/CD, monitoring, high availability, scalability, disaster recovery, and cost optimization.

### Overall Assessment

Overall, the internship helped me transform my AWS knowledge from a primarily theoretical understanding into practical experience with a real-world system. Through CloudMenu, I gained a better understanding of how AWS services can be integrated to build a complete application, as well as the key factors that need to be considered regarding architecture, security, cost, scalability, and operations.

This experience provides an important foundation for me to continue developing my skills in Cloud Computing, AWS Infrastructure, and Cloud-Native Application Development in the future.
